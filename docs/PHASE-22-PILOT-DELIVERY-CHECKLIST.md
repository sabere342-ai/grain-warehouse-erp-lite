# المرحلة 22 - قائمة تجهيز تسليم النسخة التجريبية

## قبل التسليم
- تأكد من نظافة `git status` وعدم وجود ملفات بناء أو ملفات مؤقتة.
- شغل الاختبارات: `flutter.bat test`.
- شغل الفحص: `flutter.bat analyze --no-pub`.
- ابن نسخة Windows: `flutter.bat build windows --release`.
- تأكد من وجود ملف التشغيل: `build\windows\x64\runner\Release\grain_warehouse_erp_lite.exe`.

## محتويات التسليم للعميل
- مجلد Release كامل، وليس ملف exe وحده، لأن البرنامج يحتاج ملفات DLL وبيانات بجانبه.
- دليل المستخدم العربي: `OWNER-QUICK-START-AR.md`.
- ملاحظات الإصدار العربية: `RELEASE-NOTES-AR.md`.
- تنبيه واضح: اعمل نسخة احتياطية يوميا، واحفظها خارج الجهاز إن أمكن.

## أول تشغيل عند العميل
- افتح البرنامج من ملف `grain_warehouse_erp_lite.exe` داخل مجلد Release.
- أنشئ أو سجل دخول المالك إذا كان مطلوبا.
- أنشئ صنفا بسيطا مثل قمح أو ذرة.
- أضف مشتريات بكمية وسعر شراء.
- نفذ بيع صحيح فوق الحد الأدنى.
- راجع تقرير اليوم.
- جرب إنشاء نسخة احتياطية واحفظ ملف JSON في مكان واضح.

## ممنوعات التسليم
- لا تسلم كود المصدر للعميل ضمن حزمة التشغيل.
- لا تسلم ملفات `build logs` أو ملفات `tmp`.
- لا تسلم مجلد `.dart_tool` أو مجلدات التطوير.
- لا تعتمد على الربح التقديري كمحاسبة كاملة أو ضريبية.
- لا تستعيد نسخة احتياطية فوق بيانات عميل إلا بعد فهم واضح وخطة آمنة، والتصميم الحالي يدعم الاستعادة على نظام فارغ فقط.
