# سجل ملاحظات التجربة الفعلية — النسخة التجريبية
## Grain Warehouse ERP Lite — نظام إدارة مخازن الحبوب

### تعريفات درجة الخطورة

| الدرجة | التصنيف | الوصف |
|--------|---------|-------|
| P0 | مانع تشغيل | البرنامج لا يفتح، فقدان بيانات، لا يمكن إتمام بيع أو شراء. |
| P1 | خطأ محاسبي | رصيد خاطئ، مخزون خاطئ، إجمالي خاطئ، كشف حساب خاطئ. |
| P2 | مشكلة استخدام | ميزة موجودة ولكن غير واضحة أو تمنع الاستخدام الطبيعي. |
| P3 | مشكلة توثيق | المستندات لا تطابق السلوك الفعلي للبرنامج. |
| P4 | طلب تحسين | اقتراح لميزة جديدة غير ضرورية لقبول النسخة التجريبية. |

### تعريفات حالة الملاحظة

| الحالة | الوصف |
|--------|-------|
| جديد | تم تسجيل الملاحظة ولم تراجع بعد. |
| تحت المراجعة | يتم فحص الملاحظة وتأكيدها. |
| مؤكد | تم تأكيد وجود المشكلة. |
| مرفوض بسبب عدم التكرار | المشكلة لم تتكرر ولا يمكن تأكيدها. |
| مؤجل | تم تأجيل المعالجة لمرحلة لاحقة. |
| تم الحل | تم إصلاح المشكلة. |
| تم التحقق | تم اختبار الإصلاح والتأكد من صحته. |

### أنواع الملاحظات

- خلل برمجي (Bug)
- مشكلة استخدام (Usability)
- مشكلة توثيق (Documentation)
- خطأ إدخال بيانات (Data Entry)
- طلب تحسين (Enhancement)

### خيارات القرار

- إصلاح فوري (Fix Now)
- إصلاح لاحق (Fix Later)
- توثيق فقط (Document Only)
- رفض (Reject)
- تحويل لمرحلة مستقبلية (Future Phase)

### تعليمات

1. سجل الملاحظة فور ظهورها.
2. افصل الأخطاء البرمجية عن طلبات التحسين.
3. لا تغير سلوك البيع والشراء والمخزون والنسخ الاحتياطي أثناء المراقبة.
4. اعمل نسخة احتياطية قبل أي استكشاف أو إصلاح.
5. لا تخلط طلبات الميزات الجديدة مع المشاكل.
