# Pilot Feedback Review Checklist

Use this checklist only for real pilot feedback after it is received.

- [ ] Was the observation recorded exactly as reported?
- [ ] Is the version or delivery package known?
- [ ] Is the reporter known?
- [ ] Is the affected application area known?
- [ ] Are the steps to reproduce available?
- [ ] Can the observation be reproduced?
- [ ] If not reproducible, are the missing details documented?
- [ ] Does it affect accounting?
- [ ] Does it affect customer balances?
- [ ] Does it affect supplier balances?
- [ ] Does it affect inventory?
- [ ] Does it affect sales?
- [ ] Does it affect purchases?
- [ ] Does it affect collections or supplier payments?
- [ ] Does it affect expenses?
- [ ] Does it affect reports?
- [ ] Does it affect backup or restore?
- [ ] Does it affect installation or environment?
- [ ] Does it affect owner/client documentation?
- [ ] Is the cause likely training?
- [ ] Is the cause likely data entry?
- [ ] Is the cause likely configuration?
- [ ] Is the cause likely unsupported usage?
- [ ] Can it be resolved by documentation only?
- [ ] Does it require development?
- [ ] Does it require urgent repair?
- [ ] Does it belong in the backlog?
- [ ] Should it be marked Won't Fix because it is outside accepted scope?
- [ ] Is the final category supported by evidence?
- [ ] Is the final root cause documented?
- [ ] Is the final action documented?
- [ ] Is the target phase or backlog destination documented if work is needed?
- [ ] Is the observation closed only after the decision is clear?
