# المرحلة 25 - قائمة تسليم أول عميل

هذه القائمة للمطور قبل تسليم البرنامج لأول عميل حقيقي. الهدف هو أن يكون التسليم واضحا وآمنا ويمكن تتبعه.

## قبل التسليم
- [ ] التأكد من أن Git clean.
- [ ] التأكد من وجود tag مستقر.
- [ ] تشغيل الاختبارات.
- [ ] تشغيل التحليل.
- [ ] بناء نسخة Windows release.
- [ ] إنشاء حزمة التسليم.
- [ ] التأكد من أن `build/` و `delivery/` غير داخلين في Git.
- [ ] فتح مجلد التسليم.
- [ ] التأكد من وجود ملف تشغيل البرنامج.
- [ ] التأكد من وجود دليل المالك.
- [ ] التأكد من وجود ملاحظات نسخة Pilot.
- [ ] التأكد من وجود نموذج ملاحظات Pilot.
- [ ] التأكد من وجود تعليمات النسخ الاحتياطي.

## أثناء التسليم للعميل
- [ ] فتح البرنامج أمام العميل.
- [ ] إضافة صنف تجريبي.
- [ ] تسجيل شراء تجريبية.
- [ ] تسجيل بيع تجريبية.
- [ ] مراجعة تقرير اليوم.
- [ ] إنشاء نسخة احتياطية أمام العميل.
- [ ] شرح مكان حفظ النسخة الاحتياطية.
- [ ] شرح أن النسخة الحالية لا تحتوي على cloud أو mobile أو multi-branch.
- [ ] تنبيه العميل لعدم حذف ملفات البرنامج عشوائيا.

## بعد التسليم
- [ ] تسجيل اسم المحل.
- [ ] تسجيل تاريخ التسليم.
- [ ] تسجيل نسخة البرنامج.
- [ ] تسجيل مكان حفظ نسخة التسليم.
- [ ] تسجيل أول ملاحظات للعميل.
- [ ] الاتفاق على مدة تجربة من `3` إلى `7` أيام.
- [ ] عدم إضافة مميزات جديدة قبل انتهاء التجربة.
