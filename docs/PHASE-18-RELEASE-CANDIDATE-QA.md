# المرحلة 18 - مراجعة مرشح الإصدار وجاهزية التغليف

## الهدف
هذه المرحلة للمراجعة والتثبيت فقط. لا تضيف وحدات أعمال جديدة ولا تغير قواعد التشغيل.

## نطاق المراجعة
- التأكد من أن المالك فقط يملك صلاحيات النسخ الاحتياطي والمسح.
- التأكد من أن الموظف لا يستطيع مسح البيانات أو الإلغاء أو إدارة الأصناف.
- اختبار دورة تشغيل كاملة: شراء، بيع، إلغاء بيع، نسخة احتياطية، مسح، استرجاع إلى نظام فارغ.
- التأكد من أن الرصيد الحالي مشتق من حركات المخزون فقط.
- التأكد من أن المسح لا ينشئ حركات عكسية أو إلغاءات جديدة أثناء الحذف.

## قواعد الأمان التي يجب أن تبقى
- لا تعديل مباشر للأرصدة.
- لا حذف لمستندات مرحلة بدون نسخة احتياطية وأمر مسح مالك.
- لا استرجاع فوق نظام يحتوي بيانات.
- لا دمج ولا استيراد جزئي.
- لا أسرار Firebase أو مجموعات Firestore تشغيلية.

## أوامر التحقق قبل التغليف
```powershell
flutter.bat test
flutter.bat analyze --no-pub
git diff --check
```

## ملاحظات يدوية للإصدار
- يجب تجربة حفظ ملف النسخة على Windows يدويا قبل تسليم نسخة تجريبية.
- يجب تجربة التخطيط المرئي على شاشة صغيرة وشاشة سطح مكتب.
- البناء النهائي لـ Android و Windows يتم بعد اعتماد هذه المراجعة.
