# المرحلة 23 - قائمة قبول التشغيل التجريبي

هذه القائمة مخصصة لصاحب المخزن أو من يراجع نسخة التشغيل التجريبي قبل استخدامها في يوم عمل حقيقي.

## فحص نسخة التسليم
- [ ] تشغيل البرنامج من مجلد `Release` داخل حزمة التسليم.
- [ ] التأكد من أن البرنامج يفتح بدون أخطاء عند البداية.
- [ ] التأكد من أن الواجهة عربية واتجاهها من اليمين إلى اليسار.
- [ ] التأكد من أن الخطوط والأرقام واضحة على شاشة ويندوز.
- [ ] التأكد من أن بطاقة لوحة التحكم تظهر بشكل طبيعي.

## فحص حساب المالك
- [ ] إذا كان النظام فارغا، تظهر شاشة إنشاء أول مالك.
- [ ] إنشاء أول مالك مرة واحدة فقط.
- [ ] تسجيل دخول المالك بعد الإنشاء.
- [ ] ظهور الشاشات الأساسية للمالك.
- [ ] ظهور الإعدادات والنسخ الاحتياطي للمالك فقط.

## فحص الأصناف والمخزون
- [ ] إضافة صنف حبوب باسم واضح.
- [ ] إدخال سعر بيع افتراضي عند الحاجة.
- [ ] إدخال حد أدنى للبيع عند الحاجة.
- [ ] إدخال تكلفة مرجعية عند الحاجة.
- [ ] التأكد من رفض السعر غير الصحيح.
- [ ] تسجيل رصيد افتتاحي للصنف.
- [ ] التأكد من أن الرصيد يظهر من حركات المخزون وليس من تعديل مباشر.

## فحص المشتريات والمبيعات
- [ ] تسجيل عملية شراء بسيطة.
- [ ] التأكد من زيادة الكمية بعد الشراء.
- [ ] تسجيل عملية بيع بسعر مسموح.
- [ ] التأكد من نقص الكمية بعد البيع.
- [ ] محاولة بيع بسعر أقل من الحد الأدنى والتأكد من رفضها.
- [ ] التأكد من عدم وجود حذف لفواتير أو حركات منشورة.

## فحص التقارير
- [ ] فتح تقرير اليوم.
- [ ] التأكد من ظهور مبيعات اليوم ومشتريات اليوم.
- [ ] التأكد من ظهور الربح التقديري عند وجود تكلفة مرجعية.
- [ ] التأكد من ظهور تحذير نقص التكلفة عند عدم وجود تكلفة مرجعية.
- [ ] التأكد من عرض المبالغ بصيغة جنيه واضحة وليس قرشا خاما.

## فحص النسخ الاحتياطي والاستعادة
- [ ] إنشاء نسخة احتياطية وحفظ ملف JSON خارج مجلد البرنامج.
- [ ] فتح معاينة الاستعادة للملف المحفوظ.
- [ ] التأكد من أن الاستعادة لا تتم إلا على نظام فارغ.
- [ ] عدم تجربة الاستعادة فوق بيانات تشغيل فعلية.
- [ ] التأكد من أن حذف البيانات التشغيلية لا يتم إلا بعد نسخة احتياطية ناجحة.

## عند ظهور خطأ
- [ ] قراءة رسالة الخطأ قبل تكرار العملية.
- [ ] عدم حذف ملفات البرنامج أو ملفات النسخ الاحتياطي.
- [ ] أخذ نسخة احتياطية إذا كان النظام ما زال يعمل.
- [ ] تسجيل الخطوات التي حدثت قبل الخطأ.
- [ ] إرسال الرسالة والخطوات للمطور أو مسؤول الدعم.

## قبول التشغيل التجريبي
- [ ] تمت مراجعة المسار الأساسي من إنشاء مالك إلى تقرير اليوم.
- [ ] تمت مراجعة النسخ الاحتياطي قبل أي تجربة خطرة.
- [ ] لا توجد ملاحظة تمنع تجربة النظام على بيانات محدودة.
- [ ] تم الاتفاق على عدم إدخال بيانات كثيرة قبل انتهاء فترة التجربة.
