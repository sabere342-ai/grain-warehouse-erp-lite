# المرحلة 26 - قائمة بداية تجربة أول عميل

هذه القائمة لا تضيف أي ميزة جديدة. الهدف هو تشغيل التجربة بهدوء، وتسجيل ما يحدث، وحماية بيانات العميل.

## قبل أول يوم استخدام

- [ ] التأكد من أن العميل يستخدم نسخة التسليم الصحيحة.
- [ ] تسجيل اسم المحل.
- [ ] تسجيل اسم المستخدم الأساسي.
- [ ] تسجيل تاريخ بداية التجربة.
- [ ] تسجيل مكان حفظ البرنامج.
- [ ] تسجيل مكان حفظ النسخ الاحتياطية.
- [ ] فتح البرنامج أمام العميل.
- [ ] تجربة إضافة صنف واحد.
- [ ] تجربة شراء واحدة.
- [ ] تجربة بيع واحدة.
- [ ] إنشاء نسخة احتياطية تجريبية.
- [ ] التأكد أن العميل يعرف أين يجد النسخة الاحتياطية.

## أثناء أيام التجربة

- [ ] تسجيل المبيعات يوميا.
- [ ] تسجيل المشتريات قبل البيع إذا دخلت بضاعة جديدة.
- [ ] عدم حذف بيانات عشوائيا.
- [ ] مراجعة المخزون نهاية اليوم.
- [ ] مراجعة تقرير اليوم.
- [ ] إنشاء نسخة احتياطية نهاية كل يوم.
- [ ] تسجيل أي ملاحظة في نموذج الملاحظات.

## عند ظهور مشكلة

- [ ] تصوير رسالة الخطأ.
- [ ] كتابة الخطوات التي حدثت قبل المشكلة.
- [ ] عدم تجربة حلول عشوائية.
- [ ] عدم حذف البرنامج.
- [ ] عدم حذف ملفات النسخ الاحتياطي.
- [ ] التواصل مع المطور ومعه آخر نسخة احتياطية.

## نهاية فترة التجربة

- [ ] إنشاء نسخة احتياطية نهائية.
- [ ] ملء نموذج ملاحظات العميل.
- [ ] تحديد أهم 3 مشاكل فقط.
- [ ] فصل المشاكل الحقيقية عن طلبات المميزات.
- [ ] عدم بدء تطوير جديد قبل مراجعة الملاحظات.
