# قائمة تأكيد التسليم الأول للعميل

تستخدم هذه القائمة فقط بعد أن يجرب العميل البرنامج فعلا.

## شروط التأكيد

- [ ] العميل استخدم نسخة التسليم الصحيحة.
- [ ] العميل استخدم البرنامج لمدة لا تقل عن `3` أيام أو فترة متفق عليها.
- [ ] تم تسجيل مبيعات حقيقية أو تجريبية كافية.
- [ ] تم تسجيل مشتريات أو أرصدة افتتاحية كافية.
- [ ] تم مراجعة المخزون.
- [ ] تم مراجعة تقرير اليوم.
- [ ] تم إنشاء نسخة احتياطية.
- [ ] لا توجد مشكلة تمنع البيع.
- [ ] لا توجد مشكلة تمنع معرفة المخزون.
- [ ] لا توجد مشكلة تمنع إنشاء نسخة احتياطية.
- [ ] تم تسجيل ملاحظات العميل إن وجدت.
- [ ] تم فصل الأخطاء عن طلبات المميزات.
- [ ] العميل يفهم أن النسخة الحالية لا تحتوي على cloud أو mobile أو multi-branch.

## قرار التأكيد

- [ ] تأكيد التسليم الأول.
- [ ] استمرار التجربة.
- [ ] إصلاح مشكلة حرجة أولا.
- [ ] تحسين التوثيق فقط.
- [ ] تجميع ملاحظات للنسخة القادمة.
