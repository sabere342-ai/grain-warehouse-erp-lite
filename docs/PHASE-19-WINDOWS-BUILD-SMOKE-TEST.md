## عائق البناء الذي ظهر

ظهر عائق أثناء بناء ويندوز مع إصدارات CMake الحديثة، حيث رفض CMake ملفات Firebase C++ SDK المستخرجة بواسطة إضافات Flutter بسبب حد توافق قديم في ملفات CMake التابعة للطرف الثالث.

بعد إصلاح حد التوافق، ظهر عائق آخر في مرحلة التثبيت/النسخ الخاصة بـ MSBuild، حيث حاولت خطوة التثبيت النسخ إلى:

`C:\Program Files\grain_warehouse_erp_lite`

بدلا من مجلد حزمة البناء المحلي.

## إصلاح توافق CMake

تم الاحتفاظ بإصلاح محدود في [windows/CMakeLists.txt](../windows/CMakeLists.txt) بعد سطر:

```cmake
cmake_policy(VERSION 3.14...3.25)
```

الإصلاح:

```cmake
set(CMAKE_POLICY_VERSION_MINIMUM 3.5 CACHE STRING "CMake policy floor" FORCE)
```

الغرض منه ضبط حد توافق صريح لملفات CMake القديمة المستخرجة من إضافات Flutter، ومنها Firebase.

## إصلاح مسار التثبيت

تم الاحتفاظ بإصلاح محدود في [windows/CMakeLists.txt](../windows/CMakeLists.txt) بحيث يتم فرض:

```cmake
set(CMAKE_INSTALL_PREFIX "${BUILD_BUNDLE_DIR}" CACHE PATH "..." FORCE)
```

بدلا من الاعتماد على شرط `CMAKE_INSTALL_PREFIX_INITIALIZED_TO_DEFAULT`. الغرض منه جعل خطوة التثبيت تنسخ ملفات التشغيل إلى مجلد مخرجات البناء المحلي بجانب الملف التنفيذي.

## الأوامر والنتائج

- `git status`: أظهر تعديلا واحدا في `windows/CMakeLists.txt` قبل إنشاء هذا التقرير.
- `git diff -- windows/CMakeLists.txt`: أكد أن التغيير الأولي كان إصلاح توافق CMake، ثم تمت إضافة إصلاح مسار التثبيت.
- `flutter.bat clean`: نجح بعد تشغيله بصلاحيات مناسبة لأدوات Flutter؛ المحاولة الأولى داخل القيود انتهت بانتهاء مهلة دون مخرجات.
- `flutter.bat pub get`: نجح. ظهرت ملاحظة عن وجود 28 حزمة لها إصدارات أحدث غير متوافقة مع القيود الحالية، وليست عائقا لهذه المرحلة.
- `flutter.bat test`: نجح، 227 اختبارا.
- `flutter.bat analyze --no-pub`: نجح، لا توجد مشاكل.
- `flutter.bat build windows`: نجح، وتم إنتاج الملف التنفيذي.

ظهرت أثناء البناء تحذيرات غير مانعة:

- تحذير CMake deprecation داخل Firebase C++ SDK المستخرج.
- تحذير ربط `LNK4078` عن أقسام `.voltbl` متعددة.

لم تمنع هذه التحذيرات اكتمال البناء.
