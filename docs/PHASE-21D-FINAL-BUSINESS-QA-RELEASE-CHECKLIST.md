# المرحلة 21D - قائمة فحص التسليم للمالك

## الهدف
هذه القائمة لفحص النسخة كما سيستخدمها مالك مخزن غلال حقيقي. يجب استخدام بيانات تجريبية وواضحة.

## قائمة الفحص اليدوي
- [ ] إنشاء صنف جديد.
- [ ] إدخال تكلفة مرجعية اختيارية.
- [ ] إدخال سعر بيع افتراضي.
- [ ] إدخال حد أدنى للبيع.
- [ ] إضافة مشتريات واستلام كمية مخزن.
- [ ] تنفيذ بيع صحيح فوق الحد الأدنى.
- [ ] محاولة بيع أقل من الحد الأدنى والتأكد أنه مرفوض.
- [ ] مراجعة المخزون بعد الشراء وبعد البيع.
- [ ] مراجعة سجل المستندات.
- [ ] مراجعة تقرير اليوم.
- [ ] مراجعة الربح التقديري.
- [ ] مراجعة تحذير نقص التكلفة المرجعية.
- [ ] تجربة النسخ الاحتياطي وحفظ ملف JSON.
- [ ] تجربة الاستعادة على نظام فارغ.
- [ ] تجربة مسح بيانات الأعمال للمالك فقط بعد النسخ.
- [ ] بناء نسخة Windows.
- [ ] التأكد من مكان ملف التشغيل النهائي:
  `build\windows\x64\runner\Release\grain_warehouse_erp_lite.exe`
