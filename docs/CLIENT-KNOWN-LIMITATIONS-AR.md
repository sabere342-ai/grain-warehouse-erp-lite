# حدود ومعروف — برنامج غلال (النسخة التجريبية)

## حدود تقنية

| الحد | الوصف |
|------|-------|
| **جهاز واحد فقط** | البرنامج يعمل على جهاز Windows واحد فقط. لا يوجد دعم لعدة أجهزة. |
| **بدون مزامنة سحابية** | البيانات تبقى على الجهاز المحلي فقط. لا توجد مزامنة مع السحابة. |
| **بدون تطبيق موبايل** | لا يوجد تطبيق للهواتف المحمولة. |
| **بدون مزامنة حية** | لا توجد مزامنة حية بين أكثر من جهاز. |
| **نسخة غير موقعة** | النسخة غير موقعة بشهادة أمان رقمية. قد تظهر رسالة تحذير من Windows SmartScreen. |

## حدود وظيفية

| الوظيفة | الحالة |
|---------|--------|
| الدفعات المقدمة | قد تكون محدودة في النسخة التجريبية |
| الرصيد السالب للعملاء | غير مدعوم — الرصيد لا يقل عن صفر إلا مع إعداد خاص |
| التقارير المالية المتقدمة | متاحة بشكل أساسي |
| كشف حساب العميل والمورد | متاح |
| النسخ الاحتياطي | متاح — الإصدار الثالث يحتوي على بيانات المنشأة والشعار |
| الاسترجاع | متاح فقط إلى نظام فارغ |

## ما هو خارج نطاق هذه النسخة

- **لا يوجد سحابة:** لا مزامنة، لا خادم، لا اتصال بالإنترنت مطلوب.
- **لا يوجد موبايل:** لا تطبيق للهواتف.
- **لا يوجد تحديث تلقائي:** يجب تحميل النسخة الجديدة يدوياً من المطور.
- **لا يوجد تعدد مستخدمين:** النظام لمستخدم واحد فقط (المالك و/أو موظف بتصاريح محدودة).
- **لا يوجد نظام ضرائب:** النظام لا يحسب الضرائب تلقائياً.

## ملاحظات أمان البيانات

- **البيانات على جهازك فقط:** جميع البيانات محفوظة على جهازك المحلي.
- **لا نسخ احتياطي تلقائي:** يجب عمل نسخة احتياطية يدوياً في نهاية كل يوم.
- **النسخ الاحتياطي للاسترجاع على نظام فارغ:** لا يمكن استرجاع البيانات فوق بيانات موجودة.
- **حذف البرنامج لا يحذف البيانات:** بياناتك في `%APPDATA%` تبقى حتى تحذفها يدوياً.

## إصدار تجريبي

هذه النسخة مخصصة للتقييم والتجربة قبل اعتماد النظام في بيئة العمل الحقيقية. بعض الوظائف قد تكون محدودة أو غير مكتملة مقارنة بالنسخة النهائية.

## الدعم الفني

عند واجه مشكلة:
1. اكتب وصف المشكلة ببساطة.
2. أرسل صورة للشاشة إن أمكن.
3. اذكر تاريخ العملية والخطوات التي سبقت المشكلة.
4. لا تحاول تعديل قاعدة البيانات يدويا.
5. تواصل مع المطور ومعك آخر نسخة احتياطية.
