# قواعد أنواع البيانات

## تخزين الأموال

كل قيمة مالية داخل النظام تخزن كعدد صحيح بوحدة القرش. مثال: `125.50` جنيه تخزن كقيمة `12550` قرشا.

هذا يمنع أخطاء التقريب التي تظهر عند استخدام الأرقام العشرية، ويسهل جمع الأرصدة ومراجعة القيود لاحقا بدقة.

## تخزين الأوزان

كل وزن أو كمية أو رصيد مخزون يخزن كعدد صحيح بوحدة الجرام. مثال: `1` كجم تخزن كقيمة `1000` جرام، و`1.25` طن تخزن كقيمة `1250000` جرام.

استخدام الجرام يجعل كل عمليات المخزون موحدة، سواء عرض المستخدم الكمية بالكيلو أو الطن.

## منع double

يمنع استخدام `double` أو `float` أو أي تخزين عشري في الأموال أو الأسعار أو الأرصدة أو المخزون أو الكميات أو الأوزان.

السبب أن الأرقام العشرية في البرمجة قد تنتج فروقا صغيرة غير مرئية للمستخدم، لكنها خطيرة في الحسابات المالية والمخزنية.

## حساب إجمالي السطر

سعر البيع أو الشراء يخزن كعدد صحيح بوحدة قرش لكل كيلوجرام.

معادلة إجمالي السطر:

```text
lineTotalPiasters = quantityGrams * pricePiastersPerKg / 1000
```

بعد الضرب والقسمة يتم التقريب لأقرب قرش باستخدام قاعدة واحدة ثابتة في كل النظام.

## العرض للمستخدم

يمكن للواجهة عرض القيم بصيغة مفهومة مثل:

- `125.50 ج.م`
- `0.5 كجم`
- `1.25 طن`

لكن التخزين والحساب الداخلي يظل دائما بالأعداد الصحيحة: القروش للأموال، والجرامات للأوزان.
