# سجل المشاكل والملاحظات — جلسة العرض التجريبي

> الإصدار: 1.0.0+1 | تاريخ البناء: 2026-07-25 | المرحلة: 99

---

## الغرض

تسجيل أي مشكلة أو ملاحظة تظهر أثناء جلسة العرض التجريبي مع العميل.

---

## تعليمات

1. **لا تكرر العملية الفاشلة** إذا كانت تخص رصيد عميل أو مخزون. سجل المشكلة أولاً ثم راجع المطور.
2. **خذ نسخة احتياطية** قبل أي تجربة كبيرة.
3. **سجل المشكلة كما حدثت** بدون تعديل البيانات يدوياً.
4. **صوّر الشاشة** عند ظهور أي خطأ.
5. **اكتب رقم الخطوة** من سيناريو العرض.

---

## درجات الخطورة

| الدرجة | الوصف |/action |
|--------|-------|--------|
| **حرج (Critical)** | يؤثر على الأرصدة أو المخزون أو يمنع التشغيل | إيقاف فوري + إبلاغ المطور |
| **عالي (High)** | يؤثر على فاتورة أو تقرير مهم | إيقاف العملية + تسجيل |
| **متوسط (Medium)** | مشكلة استخدام أو عرض لكن البيانات سليمة | تسجيل + المتابعة لاحقاً |
| **منخفض (Low)** | ملاحظة بسيطة أو تحسين مقترح | تسجيل |

---

## تصنيف المشكلة

| التصنيف | الوصف |
|---------|-------|
| **خلل (Defect)** | خطأ في المنطق أو الحساب |
| **مشكلة استخدام (Usability)** | واجهة غير واضحة أو صعبة |
| **طلب عميل (Client Request)** | ميزة جديدة يطلبها العميل |
| **مشكلة تدريب (Training Issue)** | العميل يحتاج شرحاً إضافياً |
| **مشكلة بيئة (Environment Issue)** | مشكلة في الجهاز أو النظام |
| **طلب خارج النطاق (Out-of-Scope)** | ميزة غير متوفرة حالياً |

## شروط الإيقاف الفوري

**أوقف الجلسة فوراً إذا حدث أي مما يلي:**

- أصبح رصيد العميل أو المورد غير صحيح.
- أصبح المخزون غير صحيح.
- تعطل البرنامج أثناء تسجيل عملية.
- فشل النسخ الاحتياطي.
- ظهر كود مصدر أو ملفات تطوير في حزمة التسليم.
- اختفى مستند بشكل غير متوقع.
